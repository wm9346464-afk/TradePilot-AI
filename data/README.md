# 合成演示数据说明

`demo_market_data.csv` 是 TradePilot AI 公开版的合成演示数据，不代表真实市场行情，
不能用于投资、交易或生产决策。

## 来源与复现

- 生成脚本：`scripts/generate_demo_data.py`
- 随机种子：`2026`
- 生成时间：`2026-10-07`（Asia/Shanghai）
- 生成方式：固定随机种子 + 趋势项 + 周期项 + 正态扰动
- 行数：374
- 起始日期：`2024-06-03`
- 实际结束日期：`2025-12-12`

运行以下命令可以重新生成同名 CSV。注意：该命令会覆盖数据文件，修改前请先确认。

```bash
python scripts/generate_demo_data.py
```

## 日期规则

生成器只保留周一至周五，并跳过中国法定节假日（元旦、春节、清明、劳动节、
端午、中秋、国庆）。周末和节假日不会产生价格点。

数据范围固定为 `2024-06-03` 至 `2025-12-12`，不向 2026 年顺延。该区间内
全部工作日为 400 天，跳过中国法定节假日后得到 374 个有效交易日；本项目优先
保证日期真实、不构造节假日行情，因此不为了凑 400 行而越界。

## 字段含义

| 字段 | 含义 |
|---|---|
| `date` | 合成数据日期 |
| `rb_close` | 螺纹钢期货合成收盘价 |
| `hc_close` | 热卷期货合成收盘价 |
| `cold_roll_close` | 冷轧现货合成收盘价 |
| `rb_spot` | 螺纹钢现货合成价 |

所有价格均为演示用数值，不代表任何交易所、品种或合约的真实报价。
